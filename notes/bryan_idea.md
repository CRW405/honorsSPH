# Physics Honors Project

## Goal
* Learn about fluid mechanics
    * Density, fluidity, and pressure
* Create an app that simulates 2D fluid mechanics
    * Make it appealing to the class
    * Apply concepts from *University Physics Volume 1* textbook

## End Product
* 2D fluid sim app
* Presentation on fluid mechanics

## Features
* Mouse interaction with particles
    * similar to David Li fluid particle simulator
* Have round particles that allow the user to do things
* Have UI for user to adjust density, speed, fluidity of particles
* Allow user to place particles wherever they please

## Tech Stack
* Python, Numpy + SciPy, Raylib
    * Numpy and SciPy to handle heavy math (matrics)
    * Look into Raylib
