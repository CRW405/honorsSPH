
# Honors SPH Fluid Sim

## Description

A 2D SPH fluid sim for a physics honors contract.

## Tech

- Python
- Numpy
- Scipy
- Raylib

## Goals

- Real time 2D SPH fluid sim using particles for presentation.
- Model: Density, Fluidity, Pressure.
- Spawn liquid with a click.
- Ability to adjust: Density, Fluidity, Pressure
